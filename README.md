# BwithU Website

This folder contains a simple static website for the BwithU browser extension.

## Files

- `index.html` - landing page structure
- `styles.css` - responsive styling and layout
- `script.js` - minimal frontend behavior

## Run locally

Open `index.html` in a browser, or use a static server such as:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
